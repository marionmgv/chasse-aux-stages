# Chasse aux stages – CAP EPC

Répertoire de magasins pour la recherche de PFMP (Saint-Étienne, Rive-de-Gier et alentours, Saint-Chamond, Givors).
LP Notre-Dame des Collines – Rive-de-Gier.

## Mise en ligne (GitHub Pages)
1. Déposer `index.html` à la racine du dépôt.
2. Settings → Pages → Source : « Deploy from a branch », branche `main`, dossier `/ (root)` → Save.
3. Le site est disponible à l'adresse `https://<identifiant>.github.io/<nom-du-depot>/`.

## Mettre à jour les données
1. Ouvrir le site → onglet « Espace enseignant » → modifier / ajouter les fiches.
2. Cliquer « Télécharger le logiciel mis à jour » : un nouveau `index.html` est téléchargé.
3. Sur GitHub : Add file → Upload files → déposer ce `index.html` (il remplace l'ancien) → Commit changes.
   Le site se met à jour en une à deux minutes.
